# Super Mario University Project

Quando studiavo all'università ho creato questo semplice progetto altro non è che un semplice fork in Qt e C++ dei primi due livelli di Super Mario Bros. a cui si aggiunge un semplicissimo Bowser verso la fine. Da considerarsi esclusivamente come un progetto didattico che sto cercando di sviluppare un altro po'. Se stai leggendo questo sappi che puoi prendere una qualsiasi linea di codice e riusarla come meglio credi.

#######################################################################################

When I was studying at university I created this simple project, it is nothing more than a simple fork in Qt and C ++ of the first two levels of Super Mario Bros. to which is added a very simple Bowser towards the end. To be considered exclusively as a didactic project that I am trying to develop a little more. If you are reading this, know that you can take any line of code and reuse it as you see fit.
